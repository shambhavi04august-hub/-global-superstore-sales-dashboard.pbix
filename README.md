# 📊 Global Superstore Dashboard (Power BI)

## 📊 Overview
This project presents an interactive Power BI dashboard analyzing global sales, profit, and customer trends using the Superstore dataset.

## 🎯 Objectives
- Analyze sales performance 📦  
- Track profit trends 💰  
- Identify top-performing regions 🌍  
- Understand customer segments 👥  

## 📊 Features
- KPI cards (Sales, Profit, Orders)  
- Region-wise analysis  
- Category & segment breakdown  
- Time-based trends  
- Interactive filters  

## 🛠 Tools Used
- Power BI  
- Data Modeling  
- DAX
